# ShopEase - E-Commerce Web Application

ShopEase is a modern, responsive, frontend-only e-commerce website built with HTML, CSS, and Vanilla JavaScript. It features product listings, cart management, localStorage persistence, product previews, login/signup validation, and a simulated checkout experience.

## Features

- Responsive homepage with modern dark-themed UI
- Dark and light mode toggle
- Product listing cards with embedded images
- Product categories section
- Product search, category filtering, and sorting
- Add to cart functionality
- Cart sidebar with persistent localStorage data
- Increase and decrease item quantity
- Remove items from cart
- Total price calculation
- Empty cart UI
- Fake checkout button
- Product details modal
- Frontend-only login and signup modal with JavaScript validation
- Toast notification system
- Smooth animations, transitions, and hover effects
- GitHub Pages friendly static file structure

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- localStorage

## GitHub Pages Deployment Steps

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository settings.
4. Go to **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/root` folder.
7. Save the settings.
8. Your live website will be available at:

```text
https://gssriram9050.github.io/REPOSITORY-NAME/
```

## Project Notes

- This project is completely static.
- No React, Node.js, npm, backend, APIs, databases, Firebase, or external hosting are required.
- No real payment integration is included.
- Cart data is saved in the browser using localStorage.
- The website works directly in any modern browser.
